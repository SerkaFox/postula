# Ilustraciones

Generadas por el orquestador con **Codex CLI** (`codex exec`, herramienta `image_generation`) en un mismo estilo: ilustración 3D suave tipo arcilla/vidrio, paleta índigo #4f46e5, azul cielo, ámbar, esmeralda y rosa, sin texto ni logos. Después se optimizaron a WebP (y JPEG para la imagen social).

| Archivo | Uso | Prompt (resumen) |
|---|---|---|
| `public/illustrations/hero.webp` | Portada | Pila de tarjetas de ofertas flotando con píldoras de estado de colores y un avión de papel; fondo índigo-50 a blanco; 16:9. |
| `public/illustrations/agents.webp` | Sección "equipo de 3 agentes" | Tres robots alrededor de una ventana de código: índigo con portapapeles (orquestador), azul con llave inglesa y teclado (develop), esmeralda con lupa y escudo con check (testing); flechas formando un bucle. |
| `public/illustrations/empty.webp` | Estado vacío del panel | Bandeja/carpeta vacía con lupa y un destello; fondo transparente. |
| `public/illustrations/auth.webp` | Login / registro | Candado, escudo y llave flotando junto a un portátil con tarjetas de colores; 3:4. |
| `public/illustrations/og-bg.jpg` | Fondo de la imagen Open Graph | Degradado índigo-violeta con las tarjetas y el avión a la derecha; mitad izquierda libre para el texto. |
